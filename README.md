# AI Reel Script Generator

AI Reel Script Generator is a full-stack AI web application that generates short-form reel scripts based on user inputs such as topic, niche, platform, and style.

## Features
- Generate viral reel title
- Generate hook
- Generate full reel script
- Generate CTA
- Generate hashtags
- React frontend
- Express backend
- Gemini AI integration

## Tech Stack
Frontend: React, Vite  
Backend: Node.js, Express.js  
AI: Gemini API  

## How to Run

### Backend
cd backend
npm install
npm start

### Frontend
cd frontend
npm install
npm run dev

## API Endpoint
POST /api/ai/generate

## Input Fields
- topic
- niche
- platform
- style

## Output
- Viral Title
- Hook
- Full Script
- CTA
- Hashtags
